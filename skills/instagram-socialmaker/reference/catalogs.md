# Catalogs, menus and orders by WhatsApp

When people keep asking "how much?" and "do you have it in black?", the answer is a catalog: every product with photos, price and options in one link, and a button that sends the order by WhatsApp already written.

## What a catalog that sells has

- Real photos of the product (several if it has details).
- The price, visible. No "DM for price".
- Options: size, color, scent, finish.
- A short description with what people ask: measurements, material, delivery time.
- Sold-out items marked, not deleted.
- How to buy: how they pay, how it arrives.
- An order button that opens WhatsApp with the products, options and total.

## Write mode

Turn the user's list (even a messy WhatsApp message or a photo of a price list) into clean categories and product entries: name, price, options, one-line description. Then the caption and story to launch it.

## Build mode

1. `get_menu_toolkit` to see the catalog and menu designs and what each field supports.
2. Build it with `create_menu` (type catalog, menu or portfolio), show `preview_menu`, adjust with `update_menu`.
3. On yes, `publish_menu`, and give the public link.
4. Offer: the link as a button in the link in bio, and an automation so «CATÁLOGO» / "CATALOG" in a comment or DM sends it.
