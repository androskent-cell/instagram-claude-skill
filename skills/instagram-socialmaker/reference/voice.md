# The user's voice

Everything sounds better in the user's own words. Build a short voice note once and reuse it.

## Ask once

"Send me 3 captions you wrote and liked, or tell me in 30 seconds: who do you talk to, how do you greet them, and which words would you never use?"

## Write the note (keep it under 10 lines)

```
Who: {audience, age, city or country, language}
Tone: {e.g. warm and direct, a bit of humor, never formal}
Greeting: {«¡Hola, hermosa!» / "Hey friend" / none}
Uses: {3-5 words or expressions they say}
Never: {words they hate, topics to avoid}
Spanish: {tú / usted; country-specific words}
Emojis: {none / 1-2 / many}
Offer: {what they sell and the price range}
```

In Claude Code, save it as `~/.claude/instagram/voice.md`. In the Claude apps, ask the user to paste it at the start of a chat or keep it in a Project.

Use it on every caption, script and DM. If a draft breaks it, fix the draft, not the note.
